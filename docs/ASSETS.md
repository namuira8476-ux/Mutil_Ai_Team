# 디자인과 자산

- UI는 연필 그림 작업실을 기반으로 중앙 대화와 오른쪽 에이전트를 배치합니다.
- 캐릭터 아틀라스는 이 프로젝트를 위해 ImageGen으로 생성했습니다. 런타임 자산은 public/assets에 포함됩니다.
- 공급자 이름은 연결된 CLI를 구분하기 위한 것이며 공식 마스코트나 공식 공급자 앱이라는 뜻이 아닙니다.
- 아이콘은 lucide-react, 글꼴은 OS 기본 글꼴을 사용합니다. 각 의존성의 라이선스가 적용됩니다.
- README 데모 이미지는 테스트용 CLI로 실행한 화면이며 실제 계정 데이터가 아닙니다.
