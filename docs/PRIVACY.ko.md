# 계정과 개인 데이터

Agent Studio 설치파일에는 개발자의 CLI 인증, API 키, 브라우저 로그인,
대화 기록, 개인 프로젝트 또는 구독이 포함되지 않습니다.

새 Windows 사용자 환경에서는 빈 프로젝트 목록과 기본 공용 스킬로 시작합니다.
CLI 경로는 설치한 사람의 PC에서 탐색합니다. 설정의 **설치 확인**은 실행파일과
버전을 확인했다는 뜻이며, 계정 로그인이나 유료 모델 사용 권한의 확인은 아닙니다.

1. 설정에서 CLI 경로를 자동 연결하거나 공식 설치를 실행합니다.
2. 설치 터미널에서 해당 CLI를 실행하고 공식 로그인 안내에 따라 **본인 계정**으로 로그인합니다.
3. 자신의 프로젝트를 추가하고 요청을 보냅니다. 사용량과 구독 한도는 자신의 계정에 적용됩니다.

이미 해당 Windows 사용자로 로그인한 CLI는 기존 인증을 사용합니다.
직접 설정한 API 환경변수도 해당 사용자 환경에서 상속될 수 있습니다.
Agent Studio가 계정 비밀번호를 수집하거나 개발자의 인증 파일을 복사하지 않습니다.
CLI별 인증은 각 CLI가 관리하며, 계정 전환은 해당 CLI의 공식 절차를 사용하세요.

앱 기록과 내장 브라우저의 쿠키는 Windows 사용자별
`%APPDATA%\agent-workroom`에 저장됩니다. 같은 Windows 계정을 공유하면
이 로컬 데이터와 CLI 인증도 공유될 수 있으므로 사람마다 별도 Windows 계정을 사용하세요.
앱 재설치나 업데이트는 기존 로컬 데이터를 유지합니다.

다른 사람에게 전달할 때는 GitHub Release 설치파일이나 소스 링크를 공유하세요.
AppData 폴더, CLI 인증 폴더, 개인 프로젝트, 설정 내보내기 파일은 배포용이 아닙니다.
설정 내보내기에는 프로젝트 경로나 직접 작성한 스킬 내용이 포함될 수 있습니다.
모델에 보낸 요청은 해당 서비스로 전송되며 완전 오프라인 처리는 아닙니다.

배포 파이프라인은 추적 파일과 실제 패키지 리소스에서 개인 경로, 인증 파일,
알려진 키 패턴을 검사하고 발견하면 업로드를 중단합니다. 패턴 검사만으로 모든
개인정보를 판별할 수는 없으므로 문서와 이미지도 별도로 검토해야 합니다.
