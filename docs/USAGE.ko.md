# Agent Studio 사용법

## 1. 설치와 연결

[AI 설치 안내](AI-INSTALL.md)의 한 줄 명령이나 GitHub Release 설치 파일을 사용합니다. 설정에서 **경로 자동 연결**을 누르면 설치된 CLI를 찾습니다. 없는 CLI는 **공식 설치 실행**으로 설치 터미널을 열고, 로그인과 권한 확인은 직접 완료합니다.

## 2. 프로젝트와 질문

프로젝트 추가로 작업할 로컬 폴더를 선택합니다. raw는 입력 자료, wiki는 정리한 지식, outputs는 결과 파일에 사용합니다. 중앙 아래에 요청을 입력하면 답변이 중앙에 쌓입니다. 기본 모델 또는 이번 요청 모델을 선택할 수 있습니다.

**팀에게 맡기기**는 Codex가 공용 스킬을 담당 CLI에 위임합니다. Gemini를 우선 사용하고, 작업 범위가 겹치지 않는 경우 최대 3개 작업을 병렬 처리합니다. 직접 지정한 모델을 우선합니다.

## 3. 진행 상황

중앙 상단에서 작업 내용, 경과 시간, 마지막 CLI 출력 시간, 대기 이유를 확인합니다. 출력이 없다는 것만으로 작업 중단을 뜻하지는 않습니다. 열린 직접 조작 CLI가 프로젝트를 점유하면 자동 작업이 기다립니다. 수동 작업을 마친 뒤 **CLI 종료하고 대기 작업 진행**으로 이어갑니다.

오른쪽 모니터는 실제 CLI 로그/직접 조작 창을 엽니다. 파란 선은 호출, 빨간 선은 응답을 나타내며 작업이 끝나면 사라집니다.

## 4. 결과 찾기

답변 아래 **결과·변경 파일**에서 **열기**, **파일 위치**, **경로 복사**, **결과 폴더 열기**를 사용합니다. 자식 에이전트가 만든 파일도 함께 표시합니다. 삭제되거나 이동된 파일은 현재 파일 없음으로 표시됩니다. 스크립트·실행파일은 파일 위치에서 확인하며 자동 실행하지 않습니다.

## 5. 내장 브라우저

중앙 위 **내장 브라우저**에서 주소를 입력하고 **이동**을 누릅니다. Codex가 연결된 브라우저 도구로 페이지 읽기·입력·클릭을 수행할 수 있습니다. 로그인과 추가 인증은 직접 입력하세요. **Codex 제어**를 해제하면 AI 조작을 중지합니다. 현재 Claude/Gemini의 직접 브라우저 제어는 지원하지 않습니다. 고정폭 페이지는 가로폭에 맞게 축소하며 세로 스크롤은 페이지 내부에서 움직입니다.

## 6. 스킬과 자동화

공용 스킬 탭에서 역할과 지침을 정의합니다. 스킬은 모델과 별개이며 선택한 CLI의 자식으로 표시됩니다. 자동화에서는 프로젝트·실행 조건·단계별 CLI·스킬·모델을 설정합니다. 실제 동작 여부를 시험 실행으로 확인한 뒤 사용하세요. 작업실이 종료된 동안에는 로컬 자동화가 실행되지 않습니다.

## 7. 데이터와 이전

설정/기록은 `%APPDATA%\agent-workroom`, 실제 자료와 결과는 선택한 프로젝트 폴더에 저장됩니다. 다른 PC로 이전할 때는 [이전 가이드](MIGRATION.ko.md)를 따르세요. 각 CLI의 로그인은 새 PC에서 다시 진행합니다.
