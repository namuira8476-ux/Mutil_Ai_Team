Agent Studio — 로컬에서 Codex, Claude, Gemini(agy)를 함께 사용하는 AI 작업실입니다.

- Windows x64 설치 파일. 앱 설치에 Node.js나 Git이 필요하지 않습니다.
- 중앙 대화와 결과 파일, 오른쪽 에이전트 캐릭터, 공용 스킬과 프로젝트 자동화.
- 실행 상태·대기 이유 표시, 내장 브라우저, CLI 자동 탐색 및 설치 터미널.
- 각 CLI의 설치·로그인과 사용 권한은 별도로 필요합니다.
- 개발 미리보기이며 설치파일은 코드서명되지 않았습니다.

설치: README의 한 줄 PowerShell 명령 또는 아래 setup.exe를 사용하세요. SHA256SUMS.txt로 다운로드 파일을 확인할 수 있습니다.
